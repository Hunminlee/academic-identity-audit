# Research profile
This profile is intended for the May 15 to Aug.15, 2026 academic signal audit. 


## Current / core

### EMG-based gesture recognition, adaptive motor decoding
ACM classification: I.5.4 - pattern recognition - Applications

This area develops robust decoding of EMG and neural signals for gesture decoding and rehabilitation-based motor interfaces. 
It emphasizes robust gesture recognition performance, in a setting where we need to ensure inter-session robustness and inter-subject robustness.

Public datasets we want to incorporate for thorough assessment: Ninapro datasets
